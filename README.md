# Kolm rakendust (Windows Forms)

**Eesmärk:** Luua kolm rakendust keeles C# ilma tööriistakasti (Toolbox) kasutamiseta, ainult koodi abil.

**Kirjeldus:** Peamenüüst saab avada pildivaataja, matemaatika viktoriini ja mängu „Paarid”. Menüü sulgemisel naaseb rakendus eelmisele ekraanile.

**Tehnoloogiad:** C#, Windows Forms, Visual Studio, objektorienteeritud programmeerimine.

**Käivitamine:** Avage projekt Visual Studios, vajutage klahvi F5 ja valige menüüst rakendus.

## Ideed edasiseks arendamiseks

**Pildivaataja:** slaidiesitus, pildi salvestamine teises formaadis, nupud „Tagasi“ ja „Edasi“.

**Matemaatiline viktoriin:** raskusastme valik, punktide arvestamine, ajalise piirangu valik.

**Mäng „Paarid”:** reaalsed pildid, käikude loendur, tasemed (4x4, 6x6).

## Edasise arendamise väljavaated

Ühtne disain kõigile rakendustele ja tulemuste salvestamine faili.
